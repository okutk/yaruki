# ご褒美の大きさの物差し

rewards.js の行動(部品)ごとに、ご褒美の大きさを4つの観点で 0〜3 の点数にする(0.5 きざみ)。
行動の文の前に `t1.5 m1 e2 w1` のように書く。書かないものは 0。

**点数 = t(時間) + m(お金) + e(手間) + w(もらえる時期)** (0〜12)

レベルが上がるほど点数が大きくなるように、行動をレベルに置く。
`tests/rewards.test.js` で、レベルごとの点数の中央値が増えていくこと・隣のレベルと重なりすぎないこと・
行動の点数がレベルの目安の幅(`BANDS`)に入ることを確かめている。

## マスごとのご褒美(box)

作業の合間に、その場ですぐもらうもの。時期(w)は常に 0。

| 点数 | t 時間 | m お金 | e 手間 |
| --- | --- | --- | --- |
| 0 | 30秒くらい | 手元にある | その場で(座ったまま) |
| 0.5 | 1分 | 自販機・コンビニで数百円 | 立って取りに行く |
| 1 | 2分 | カフェで数百円〜千円 | 用意がいる(いれる・温める・場所を移る) |
| 1.5 | 3分 | | |
| 2 | 5分 | | 作る・片付けがいる・玄関の外に出る |
| 3 | 10分 | | 近所まで出かけて戻る |

## 「いつ」とひと工夫

- 「いつ」の部品(このあとすぐ・今夜・次の休みに・今月中に など)も時期 w を持つ。
  組み合わせたご褒美の時期は、行動・いつ・ひと工夫のうち一番先のもの。
- 「いつ」は、行動の時期から 0.5 早い〜1 遅いものだけ組む
  (小さいご褒美を「次の休みに」に延ばさない・日帰り旅行を「このあとすぐ」にしない)。
- 低いレベルは「今すぐ・今日のうち」だけ(レベル1・2 は時期 1 まで、3・4 は 2 まで)。
- ひと工夫にも、足す点数(例: 「いつもより少し贅沢に」は m0.5)と、合う時期の範囲
  (例: 「パジャマに着替えて」は今夜まで、「少し早起きして」は明日以降)を書ける。
